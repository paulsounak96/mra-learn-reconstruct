# mra-learn-reconstruct

Neural networks for supervised learning and reconstruction of signals and shift distributions using the Method of Moments, applied to the Multireference Alignment (MRA) problem.

## Overview

The Multireference Alignment problem involves recovering an unknown signal from noisy, circularly shifted observations. This project uses neural networks trained on first and second moments of the data to reconstruct both the original signal and the distribution of circular shifts. This repository hosts the code for the MRA portion of the paper:

[Y Khoo, S Paul, N Sharon. Deep neural-network prior for orbit recovery from method of moments. Journal of Computational and Applied Mathematics. 444, 115782](https://www.sciencedirect.com/science/article/abs/pii/S0377042724000311).

The approach leverages the fact that moments encode sufficient information about the signal and shift distribution, allowing neural networks to learn the mapping from moments to the underlying parameters.

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd mra-learn-reconstruct
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

   Required packages include PyTorch, NumPy, Matplotlib, PyYAML, tqdm, and pytest.

## Configuration

The project uses configuration files in the `config/` directory:

- `config.yaml`: Contains parameters such as signal length (`L`), shift parameter (`s`), noise level (`noise_sdmult`), number of samples (`num_samps`), training epochs (`max_epoch`), batch size (`batch_size`), learning rate (`lr`), etc.

- `config.py`: Loads the YAML configuration and allows command-line overrides.

You can modify `config/config.yaml` to adjust parameters before running the project.

## Usage

Run the project using the following three commands in sequence:

1. **Generate training data stacks**:
   ```bash
   py -m src.datamaker
   ```
   This creates combinations of shift distributions and signals, computes their moments, and saves data stacks for training.

2. **Generate single data sample**:
   ```bash
   py -m src.orchestrator
   ```
   This generates a single synthetic data sample (signal, shift distribution, noisy observations) and saves it to the `data/` directory for testing or visualization.

3. **Train the neural network**:
   ```bash
   py -m src.train
   ```
   This trains the `rhonet` model to predict shift distributions from first and second moments, using the data generated by `datamaker`. The trained model is saved as checkpoints.

After training, you can visualize results using the generated plots in the `data/stacks/` directory.

## Testing

Run the tests to verify the implementation:

```bash
pytest tests/
```

The tests include sanity checks for moment computation and circulant matrix formulations.

  - `config.yaml`: Default parameters

- `data/`: Generated data and results
  - Pre-computed tensors and visualization plots

- `tests/`: Test files for validation

- `MRA_learning_mixgauss.ipynb`: Jupyter notebook for interactive exploration

## Mathematical Background

In the Multireference Alignment problem, we observe noisy circular shifts of an unknown signal `s`:
```
y_i = s((i - shift_i) mod L) + noise
```

The goal is to recover `s` and the distribution of shifts `rho`.

This project uses the Method of Moments: compute first and second moments of the observations, then train neural networks to map these moments back to `rho` and `s`.

Key insight: The moments contain sufficient statistics for the reconstruction.
